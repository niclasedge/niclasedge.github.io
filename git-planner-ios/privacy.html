Kurzfassung

Git Planner speichert deine Daten lokal auf dem Gerät. Es gibt keinen eigenen Server, kein Login bei uns und keine zentrale Nutzer-Datenbank. Die App kommuniziert ausschließlich direkt mit der GitHub-API — mit den von dir hinterlegten Zugangsdaten.

Welche Daten verarbeitet die App?

Lokal auf dem Gerät

  • Ein lokaler Cache deiner GitHub-Daten (Repositories, Issues, Kommentare) für die Offline-Nutzung
  • Deine Schnellaufgaben (Quick Tasks) und App-Einstellungen
  • Deine GitHub Personal Access Tokens — sicher verschlüsselt im iOS-Schlüsselbund (Keychain)

Diese Daten verbleiben auf dem Gerät und werden nicht an uns übertragen. Das Widget greift über eine App Group ausschließlich lokal auf diese Daten zu.

GitHub

  • Die App kommuniziert direkt mit der GitHub-API (api.github.com), um deine Repositories und Issues zu laden und Änderungen zu synchronisieren.
  • Diese Kommunikation erfolgt mit deinen eigenen GitHub Personal Access Tokens in deinem GitHub-Konto; wir haben darauf keinen Zugriff.
  • Für die Verarbeitung durch GitHub gilt die Datenschutzerklärung von GitHub.

Tracking & Analytics

Git Planner enthält kein Analytics-, Tracking- oder Werbe-SDK. Es werden keine Nutzungsdaten erhoben.

Konten

Die App benötigt kein eigenes Konto. Du verwendest deine bestehenden GitHub Personal Access Tokens, die du jederzeit in den Einstellungen der App entfernen oder auf GitHub widerrufen kannst.

Deine Rechte

Du kannst hinterlegte Tokens jederzeit in der App löschen, den lokalen Cache durch Deinstallation der App entfernen, oder deine Daten direkt auf GitHub verwalten. Mit der Deinstallation werden alle lokalen App-Daten einschließlich der im Schlüsselbund gespeicherten Tokens gelöscht.

Änderungen

Diese Erklärung kann bei App-Updates angepasst werden. Die aktuelle Version ist unter der in App Store Connect hinterlegten URL abrufbar.
